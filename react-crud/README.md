# React CRUD - Quản lý người dùng

Ứng dụng React (CDN + Babel) gồm 4 component: App, SearchForm, AddUser, ResultTable.

## Chạy
Mở `index.html` bằng trình duyệt (cần Internet để tải React/Babel từ unpkg và dữ liệu từ jsonplaceholder).
Nếu trình duyệt chặn khi mở file trực tiếp, chạy server tĩnh trong thư mục này, ví dụ:

    python -m http.server 8000     # rồi mở http://localhost:8000

## Deploy
Đây là trang tĩnh: kéo thả thư mục này vào https://app.netlify.com/drop hoặc đẩy lên GitHub Pages.
